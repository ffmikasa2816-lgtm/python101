# AccessMap: The Missing Layer

AccessMap is a student hackathon front-end prototype exploring how place-accessibility information could communicate both the information available and its verification status.

## Features
- Search sample place records
- Filter by demo verification status
- Interactive map powered by Leaflet and OpenStreetMap (internet required)
- Demo report form

## Run
Open `index.html` in a modern web browser. The map requires an internet connection.

## Important limitations
- All included place records are illustrative demo data, not real accessibility audits.
- New reports exist only in the current page session; there is no server or database.
- New report map markers use placeholder coordinates and do not indicate the actual reported location.
- The prototype is not an official accessibility certification.
